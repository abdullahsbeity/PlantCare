# PlantCare Sample Project

A responsive Flutter sample project prepared for the CSCI410 Phase 1 GitHub requirement.

## Included in this sample
- Responsive layout: bottom navigation on narrow screens and navigation rail on wider screens.
- Four sections: Overview, My Plants, Watering Schedule, and Care Tips.
- Sample plant data held in memory.
- Add a plant and mark a plant as watered.
- Watering dates calculated from the last watered date and the selected interval.

## Important assignment notes
- No database is used.
- No online services or APIs are used.
- Data is stored only in memory and resets when the app restarts.
- This is a starter/sample project, not the complete final PlantCare application.

## Run locally
1. Install Flutter SDK.
2. Extract this project.
3. Open a terminal in the project folder.
4. Run `flutter pub get`.
5. Run `flutter run`.

## GitHub
Create a public repository named `PlantCare` (or `PlantCare-Sample`) and upload the project source.
Do not upload build outputs or private credentials.
